# Portfolio content notes

This file is internal project guidance and is not linked from the site.

## Copy rule

Every description should answer, in plain language:

1. What is the project?
2. What did Mateo build or contribute?
3. What is the viewer looking at in the image/video?

Avoid generic portfolio language, marketing flair, and claims that are not demonstrated by the media.

## Homepage visual contract

- Keep the homepage composition frozen unless fixing a bug.
- Cobalt remains the site signal color.
- Map labels: Barlow Condensed Black, off-white.
- Transition: black physical diagonal strikes, white title; paint -> fully covered -> title/swap -> reverse unpaint.
- Station ticket shows one real asset only. No placeholder cards.
- If media is missing, leave the detail gallery smaller rather than inventing a placeholder.
