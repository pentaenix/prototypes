# prototypes

Mateo Saldivar portfolio / prototype showcase.

## Production URL

https://pentaenix.github.io/prototypes/

## Repository

This project is intended to live in the GitHub repository:

`pentaenix/prototypes`

All site URLs are relative so the site works correctly from the `/prototypes/` GitHub Pages subpath.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## GitHub Pages

This repository includes a Pages deployment workflow. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**. Every push to `main` will deploy the site.
